==========================================================
 ZENITH CLINIC — Hướng dẫn cài trên máy Windows (server nội bộ)
==========================================================

BẠN CÓ 2 FILE:
  • Chay-Zenith.bat     <-- BẤM ĐÚP VÀO FILE NÀY ĐỂ CHẠY
  • Zenith-Setup.ps1    <-- file xử lý (để CÙNG THƯ MỤC với file .bat)

CÁCH DÙNG (rất đơn giản):
  1. Để CẢ HAI file trong cùng một thư mục (ví dụ: Desktop).
  2. Bấm đúp vào  "Chay-Zenith.bat".
  3. Khi Windows hỏi quyền (UAC) -> bấm YES.
  4. Lần đầu, nếu máy chưa có Docker, file sẽ tự cài Docker Desktop:
       - Sau khi cài xong, KHỞI ĐỘNG LẠI máy.
       - Mở "Docker Desktop", đợi biểu tượng con cá voi chuyển màu XANH.
       - Bấm đúp lại "Chay-Zenith.bat" một lần nữa.
  5. Đợi vài phút (lần đầu ~5-10 phút). Xong, trình duyệt tự mở:
       http://localhost:3000
       Đăng nhập:  admin  /  123456

DỮ LIỆU LƯU Ở ĐÂU?
  • Ngay trên máy này (trong Docker). Tắt/mở máy dữ liệu vẫn còn.
  • Máy này chính là "server". Máy khác trong cùng mạng phòng khám
    vào bằng:  http://<địa-chỉ-IP-của-máy-này>:3000
    (Xem IP: mở Command Prompt, gõ  ipconfig  -> dòng IPv4 Address)

CÁC LỆNH HỮU ÍCH (mở thư mục C:\Users\<tên>\ZenithTasks rồi gõ):
  • Dừng app:        docker compose down
  • Chạy lại app:    docker compose up -d
  • Xem nhật ký:     docker compose logs -f

YÊU CẦU:
  • Windows 10/11, có kết nối Internet (để tải lần đầu).
  • Quyền Quản trị (Admin) để cài phần mềm.

LƯU Ý BẢO MẬT:
  • Khoá demo trong cấu hình chỉ để chạy thử. Khi dùng thật, nhờ kỹ thuật
    đổi AUTH_SECRET và PHONE_ENC_KEY (xem web/DEPLOY.md trong dự án).

Gặp lỗi? Chụp màn hình cửa sổ báo lỗi và gửi lại trong cuộc trò chuyện,
mình sẽ hướng dẫn xử lý.
